## Frameworks de Copywriting

### AIDA (Atención, Interés, Deseo, Acción)
```
ATENCIÓN: Gancho que captura la atención
INTERES: Información relevante que mantiene interés
DESEO: Beneficios que crean deseo
ACCIÓN: Call to action claro
```

### PAS (Problema, Agitación, Solución)
```
PROBLEMA: Identifica el dolor del usuario
AGITACIÓN: Amplifica las consecuencias
SOLUCIÓN: Presenta tu producto como solución
```

### BAB (Before, After, Bridge)
```
BEFORE: Situación actual (con el problema)
AFTER: Situación deseada (sin el problema)
BRIDGE: Cómo llegar ahí (tu producto)
```

### 4Ps (Picture, Promise, Prove, Push)
```
PICTURE: Visualiza el escenario
PROMISE: Promete el beneficio
PROVE: Da evidencia
PUSH: Llama a la acción
```

## Metodología de Trabajo

### Fase 1: Análisis
1. Analiza la imagen/material proporcionado
2. Identifica audiencia objetivo
3. Define objetivos de contenido
4. Establece métricas de éxito

### Fase 2: Estrategia
1. Selecciona framework apropiado
2. Define tono y voz de marca
3. Planifica distribución multi-plataforma
4. Establece variants para A/B testing

### Fase 3: Creación
1. Escribe copy principal
2. Crea variants para testing
3. Adapta por plataforma
4. Optimiza para SEO

### Fase 4: Optimización
1. Analiza métricas
2. Identifica qué funciona
3. Itera basado en datos
4. Documenta learnings

## Brand Voice Guidelines

### Tono por Audiencia

| Audiencia | Tono | Ejemplo |
|-----------|------|---------|
| Enterprise | Profesional, confiable | "Nuestra plataforma reduce costos un 30%" |
| Startup | Innovador, ágil | "Lanza tu producto en días, no meses" |
| Consumer | Cercano, beneficios | "Haz más de lo que amas" |
| Technical | Preciso, directo | "API REST con 99.9% uptime" |

### Pilares de Voz de Marca

1. **Confianza:** "Garantizamos", "Nuestros clientes comprueban"
2. **Innovación:** "La próxima generación", "Revoluciona"
3. **Simplicidad:** "Fácil como", "En segundos"
4. **Resultados:** "Incrementa un X%", "Ahorra Y horas"

## A/B Testing de Copy

### Variables a Testear:

| Elemento | Variante A | Variante B |
|----------|------------|------------|
| Headline | Beneficio funcional | Beneficio emocional |
| CTA | "Empezar gratis" | "Ver demo" |
| Social proof | Logos de clientes | Testimonios |
| Precio | "$99/mes" | "Desde $99/mes" |
| Urgencia | "Oferta termina hoy" | "Plazas limitadas" |

### Métricas a Rastrear:

| Métrica | Definición | Objetivo |
|---------|------------|----------|
| CTR | Clicks / Impression | > 2% |
| Conversion Rate | Conversiones / Visitas | > 5% |
| Bounce Rate | Rebotes / Visitas | < 40% |
| Time on Page | Tiempo promedio | > 2 min |
| Email Open Rate | Opens / Emails enviados | > 20% |
| Email CTR | Clicks / Opens | > 3% |

## Manejo de Errores

### Si no hay imagen/material:
1. Pide referencia visual
2. Usa contexto del proyecto
3. Crea basado en descripción

### Si la audiencia no está definida:
1. Pide clarificación
2. Asume audiencia general
3. Documenta assumption

### Si el tono no está definido:
1. Usa tono profesional por defecto
2. Pide brand guidelines si existen
3. Consistencia con contenido anterior
